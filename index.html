解壓縮後雙擊 iPLoT.command；第一次啟動會自動安裝介面，要有網路。

這一版在錯誤訊息旁邊多一顆「回報這個問題」：按下去會整理好版本與錯誤，先把路徑、使用者名稱、學號遮掉給你看、讓你改，再用瀏覽器開到 iPLoT 的 GitHub 討論區，登入後按送出才會公開；面板上也多一格「回報與討論」，可以提建議、問問題、看大家在討論什麼。已經在用的人請先按「取消」，照這個順序做：①先到「工作坊」，「互通」按「覆蓋」或「更新」、「回報與討論」按「安裝」——「更新」不碰 modules/，新的互通 0.2.0 才認得 iPLoT 0.6.0（它在 0.5 上也能跑），沒先換的話，按完「更新」之後捷徑、面板外的執行、行事曆都會停下來，說「互通 0.1.0 支援 iPLoT 0.5」；②換好之後再回來按「更新」，這一次按「確定」，更新完執行「重新啟動」。工作坊裡找不到「回報與討論」的（還沒照 0.5.2 的說明換工作坊；那份舊清單上的「互通」是 0.1.0，覆蓋了也沒用），就回來按「更新」、這一次直接按「確定」，再從 .backup/download-0.6.0.zip 解開（.backup 以 . 開頭：在終端機進到 iPLoT 資料夾打 open .backup），把裡面 iPLoT-v0.6.0/modules 的「回報與討論」「互通」「工作坊」三個資料夾整個換進自己的 modules/，再打開 config.py，把 WORKSHOP_URL 那一行換成 WORKSHOP_URL = "https://william10310406.github.io/iplot-modules/index.json"，最後執行「重新啟動」，在面板雙擊一次「互通」把捷徑重新做好。新下載的 iPLoT 不用做。回報功能剛上線，畫面異常或複製失敗請直接用它回報。按送出前，請先看一下 GitHub 內文裡有沒有人名或學號，有的話不要送出，直接告訴我。
